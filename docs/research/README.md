# Research library

A linked working library for the life manual. Research is organized by the question being answered; product proposals and child-facing content live outside this directory.

## Start here

Read the [cross-topic synthesis](report-source.md) for the overall argument, then choose a bucket. Each educational bucket has a findings page, a nearby source ledger, product links, and open questions.

| Bucket | Central question | Evidence records |
| --- | --- | --- |
| [Learning that compounds](learning/README.md) | How does earlier learning help later learning, and when does transfer fail? | [L1, L11–L13](learning/sources.md) |
| [Lifetime opportunities](lifetime/README.md) | How do preparation, requirements, time, and recovery shape options? | [L2–L10](lifetime/sources.md) |
| [Circumstances, setbacks and chance](circumstances/README.md) | How do outside conditions shape opportunities, and what can support recovery? | [C1–C22](circumstances/sources.md) |
| [Decision-making and development](decision-making/README.md) | How can children learn demanding decision concepts, with appropriate support? | [T1–T9](decision-making/sources.md) |
| [Habits](habits/README.md) | How do repeated actions become easier to initiate, and how can routines change? | [B1–B4](habits/sources.md) |
| [Delivery references](delivery/README.md) | What supports static delivery, useful prototypes, and accessible motion? | [H1–H8](delivery/sources.md) |

Habits has an initial formation evidence base. Changing established habits and child/family interventions are explicit research gaps, not completed findings.

## Keeping the library coherent

- Put each substantive finding in one topic page and its detailed source record in that topic's ledger. Cross-link when evidence serves another topic; do not copy a study record into several folders.
- Keep evidence, interpretation, fictional example, and product recommendation distinguishable. Product behavior belongs in [numbered product documents](../product/README.md).
- Preserve source identifiers and meaningful headings. Add a topic subpage when it answers a distinct question with enough evidence to justify one; link it from the bucket overview. Do not create empty topic files.
- Record publication date, access date, study population, design, measured outcome, confidence, and limitations. State when only an abstract was accessible. Maintain [the source index and research gaps](sources.md).
- Prefer current statements to progress diaries. Put current priorities in [NEXT_STEP.md](../../NEXT_STEP.md) and completed tasks in [COMPLETED.md](../../COMPLETED.md).
- Store links and proportionate paraphrases, not copied research papers or figures without the necessary rights. Generated design artwork belongs in [design studies](../design/README.md), not as research evidence.

The Markdown links are the working navigator now. A possible [research reading UI](../product/005-research-library.md) would render this same library; no web navigator is implemented.
