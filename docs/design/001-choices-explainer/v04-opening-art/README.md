# v04 — Opening path-network artwork

Status: not selected; too similar in appearance and too rough for the desired modern finish. Created: 2026-09-06. Updated: 2026-09-07.

Question: can standalone ink/paper treatments communicate abundant possible lives before adding interface controls? [Study index](../README.md) · [Visual-language proposal](../../../product/003-visual-language-and-navigation.md). This frozen round contains generated artwork, not browser captures.

One beginning opens into an abundant, irregular network of possibilities. The opening contains no chosen route, time divider, age labels, numbered dots, endpoint badges or interface controls. Ages 8+ is the reading audience, not the beginning of life.

| Study | Image | Treatment |
| --- | --- | --- |
| A | [Closest to the reference](a-closest-to-reference-v01.png) | Confident, dark-green lines on a clean white ground; strongest immediate readability. |
| B | [Botanical ink](b-botanical-ink-v01.png) | Finer, denser penwork on warm paper; most delicate field-guide treatment. |
| C | [Wandering atlas](c-wandering-atlas-v01.png) | Irregular, meandering branches with more visibly textured ink. |
| D | [Open horizon](d-open-horizon-v01.png) | Airier ink-and-wash treatment with greater line-weight variation. |

All four were generated separately with built-in ImageGen using the [original reference](https://i.redd.it/0ica4htbtm671.jpg), which was reopened and inspected. Every output was visually inspected for a single beginning, repeated branching, irregular rises/falls, abundance, line visibility, and absence of numbers and UI. These are the first four candidates in this reset, not four approved designs or a claim of multiple refinement rounds.

A is closest to the reference's graphic directness. B has the finest editorial treatment. C's texture is more pronounced. D's bolder strands can imply greater importance, which needs consideration before using that treatment for equally open paths. Generated crossings and endings are illustrative, not validated graph topology, measured opportunity counts or predictions about life. Any chosen direction needs precise geometry when later implemented.

The site is unchanged. Current exploration is the [reference baseline and modern treatments](../v05-reference-and-modern/README.md). These four images and their [exact prompt set](prompts.md) remain comparison material; all four PNGs are unchanged copies of the generated outputs.
