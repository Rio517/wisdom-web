# 001 — Choices explainer

Created: 2026-09-06. Updated: 2026-09-26. Status: v04 hiking storyboard accepted for prototyping; character Alfredo; no production visual approval.

This study asks how to explain an abundance of possible lives, one lived path, choices that change later opportunities and learning that builds over time. It groups artwork, storyboards and browser evidence for the same Choices experience; these are not separate projects.
