# Choices › The paths we make

This is the guide's first lesson. It explains what choices can change and how their effects add up over time, alongside circumstances, support and chance. It explores many possible paths, follows one fictional route to today, and shows how earlier learning can support later learning. It does not explain how the mind makes decisions. This folder holds work specific to the lesson. Guide-wide documents stay in `docs/product`, `docs/research` and `docs/design`.

See the [lesson roadmap](../README.md#lesson-roadmap) for the other planned topics and their status.

Current lesson to edit: [The paths we make — Draft 02](../content/choices-story.md). The main explanation covers possibilities, accumulated effects and what we cannot control. Alfredo’s hikes sit beneath it as an optional example with two setbacks and resilience. Edit the draft before the next round.
